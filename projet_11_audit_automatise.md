# Projet 11 : Audit Automatisé de Vulnérabilités Logicielles (DevSecOps)

-   **Dataset :** Software Defect Prediction (NASA/Promise) + DiverseVul
    / CodeXGLUE (Kaggle/GitHub).
-   **Objectif :** Analyser des dépôts de code source et bloquer
    automatiquement les déploiements à risque.
-   **Techniques :** Random Forest (analyse des métriques logicielles
    tabulaires), Transformer (analyse du code source pour failles de
    sécurité), Arbre de Décision (verdict de passage en production).
-   **Livrables :** Rapport technique, code source documenté,
    démonstration.
